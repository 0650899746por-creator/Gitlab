# Lab 03 — ตารางตรวจรับ Browser (A1–A5)

* แอปที่ตรวจ: `http://127.0.0.1:5000/` (Flask dev server, พอร์ต 5000)
* ค่าคงที่ร่วม: V_CC = 12 V, R_C = 2.2 kΩ, β = 100, V_BE = 0.70 V
* เครื่องมือที่ใช้จริง: **OpenCode Browser (Built-in) v2.3.0** — `browser_navigate`, `browser_snapshot`, `browser_click` (คลิกการ์ดโหมด), `browser_fill`, `browser_screenshot`

## ทวนผลด้วยตนเองหนึ่งกรณี (A3 → A4)

1. เปิด `/?mode=emitter` กรอก V_CC = 12, R_C = 2.2, β = 100, V_BE = 0.70, R_B = 1000, R_E = 1 → กด «คำนวณ» → I_C = 1.03 mA
2. เปลี่ยนเฉพาะ R_E เป็น 2 (ตรวจใน snapshot ว่าช่อง R_B ยังเป็น 1000) → กด «คำนวณ» อีกครั้ง → I_C = 0.94 mA
3. เส้นทางข้อมูล: ช่อง `name="re"` → `request.form["re"]` ใน `app.py` → `_collect(..., "re", "R_E", KOHM)` คูณ 1000 → `dc_bias.emitter_bias(re=2000.0)` → `(vcc - vbe) / (rb + (beta + 1) * re)` → `_operating_point` คูณ `1e3` เป็น `ic_ma` → template แสดง `{{ "%.2f"|format(result.ic_ma) }}`
4. ถ้าค่าไม่เปลี่ยน ให้ตรวจตามลำดับ: ค่าในช่องจริง → ชื่อ `name` ที่ Flask อ่าน → ตัวคูณ `KOHM` → อาร์กิวเมนต์ที่ส่งเข้า `emitter_bias` → ตัวแปรที่ใช้ในสูตร ก่อนแก้สมการ
